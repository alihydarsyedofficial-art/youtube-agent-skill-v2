# YouTube Agent Skill Framework v2.0 🚀

An advanced, zero-cost, serverless-compatible automation system for end-to-end YouTube content creation, channel auditing, retention engineering, and SEO packaging.

## 🌟 Core Architecture & Modules

- **yt-audit:** Full-channel diagnostic bottleneck matrix (CTR, AVD, Hook retention).
- **yt-plan:** Outlier multiplier validation (`>= 3.0x`) and content calendar distribution.
- **yt-script:** Multimodal scriptwriting engine powered by `hookscore.py` (6-axis psychological scoring).
- **yt-retention:** Full-timeline decay simulation & flatline detector (`retention.py`).
- **yt-edit:** Automated dead-air removal (`>0.4s`) and FFmpeg jump-cut command generator (`deadair.py`).
- **yt-chapters:** Semantic topic-shift detector and YouTube compliance validator (`chapters.py`).
- **yt-package:** High-CTR title & thumbnail synergy scorer with mobile pixel-width truncation (`title.py`).
- **yt-seo:** Search-graph metadata velocity & snippet engineering.
- **yt-shorts:** Sub-60s vertical loop engineering and high-retention cadence.
- **yt-viral:** Viral outlier deconstruction & structural DNA extractor (`swipe.py`).
- **yt-comment:** Pinned comment conversion and community velocity engine.
